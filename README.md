# Hangman Game

This is a simple Hangman game made using Python as part of my CodeAlpha internship.

## About the Project

In this game, the computer randomly selects a word and the player has to guess it one letter at a time.

The player gets a maximum of 6 wrong guesses. The game ends when the player guesses the complete word or uses all 6 wrong guesses.

## Features

- Random word selection
- Letter-by-letter guessing
- Maximum 6 wrong guesses
- Checks for repeated letters
- Checks for invalid input
- Simple command-line interface

## How to Run

Make sure Python is installed on your computer.

Open the project folder in VS Code and run:

python hangman.py
